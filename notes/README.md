> This directory contains local course notes and is intentionally excluded from GitHub.

## Organization / 目录

- `day-01/`: machine learning, optimization, reinforcement learning foundations, and course-team research presentations
- `day-02/`: multi-agent reinforcement learning and Minecraft agents
- `day-03/`: continued MARL, imitation learning, MPE2 practicals, W&B, and the DQN/PyTorch implementation study
- `project/`: reserved for future Atari Boxing tournament notes

## Writing convention / 书写约定

- 专业术语第一次出现时同时保留英文与中文。
- 先给直觉，再给正式定义、公式和例子。
- `课堂内容 / Lecture content` 表示来自当天课件或现场照片。
- `理解补充 / Learning supplement` 表示为了建立知识联系而增加的解释，不代表老师已在该页讲过。
- 代码、项目结果和课堂笔记分开保存；GitHub 仓库只保留项目代码。
